# DustUI pre-Gate-D acceptance authority

AUD-FIX-13 makes this directory the current **acceptance metadata authority**. It does not qualify Gate D.

- `validator_lifecycle.json` inventories every remaining live Android test that reads repository/source files and maps archived guards to exact successor evidence.
- `ui_acceptance_matrix.json` maps the complete authoritative UI/UX requirement index to current behavioral evidence or to an exact later Gate-D/Gate-E evidence node.
- `current_state.json` is generated by `scripts/refresh_acceptance_state.py` and describes candidate acceptance convergence separately from qualification.
- Gate-D qualification remains exclusively owned by `migration/qualification/v1/current_state.json` and executed evidence.

Quarantined app-local adb/APK/release helpers may remain until AUD-FIX-16, but current acceptance and Gate-D orchestration may not depend on them.
