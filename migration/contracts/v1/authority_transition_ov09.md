# OV09 authority transition

Go is now the package/storage evidence authority. Android may collect platform facts, but Go normalizes them, versions them, hashes them, exposes truthful UI states, and feeds cleanup eligibility.

Legacy package regex inference remains reachable only as non-authoritative diagnostic context. It cannot produce cleanup eligibility, package labels, residue labels, or review manifests without Go package/user evidence.

Android buildability remains intentionally suspended until OV13.
