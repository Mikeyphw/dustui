# OV05 shell scaffold and route contract

OV05 defines a reconnect scaffold, not final Android product UI.

Stable semantic routes:

- Overview
- Files
- Clean
- Apps
- Activity
- System

This grouping is provisional and is not an acceptance requirement for the final UI count. The acceptance contract is stable route identity, generation/entity binding, route restoration, deep-link translation, shared Loading/Empty/Blocked/Error/Content states, shared action-gate rendering, and rejection of stale async responses.

Android buildability remains intentionally-suspended until OV13, so Compose instrumentation is not a Gate-B blocker.
