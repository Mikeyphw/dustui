# OV13 legacy path reachability

After OV13, legacy implementations may still exist in source until OV14, but they must not be production authorities.

Unreachable or non-authoritative after Gate D:

- Python/Textual host runtime as production implementation;
- independent Kotlin-local scan/query/cleanup/package/automation/diagnostics truth;
- old 16-destination shell as product navigation authority;
- cleanup actions bypassing immutable manifest + single-use capability;
- package-sensitive cleanup derived from path regex alone;
- notification/Tasker/WorkManager treating accepted/queued/running as success.

Any retained adapter must be a thin bridge into Go runtime contracts.
