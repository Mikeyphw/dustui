# OV12 audit loop

Verified against the Android-suspended roadmap:

- COMPLETED alone can never produce healthy;
- stale evidence is visibly stale;
- derived health invalidates when authoritative evidence advances;
- root causes suppress dependent symptoms;
- structured diagnostics carry session/operation/parent IDs and area/severity/action/result;
- redaction happens before persistence;
- retention/pruning/export rules are deterministic;
- support bundle is sealed, reproducible, privacy-qualified, and has no automatic upload;
- Android buildability remains intentionally suspended until OV13;
- unsupported Devtool target-local jobs/workflows are not reintroduced.
