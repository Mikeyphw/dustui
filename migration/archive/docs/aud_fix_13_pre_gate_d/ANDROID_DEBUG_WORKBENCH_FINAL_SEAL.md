# Debug Workbench final seal — superseded

The former Debug Workbench final seal is archived in place for traceability and is no longer authoritative for the current tree. AUD-FIX-11 replaces its product acceptance with Activity + System → Diagnostics behavioral contracts.

The successor invariants are: durable Go operation truth in Activity; exact operation/evidence correlation; ProblemGraph root cause/remediation in Diagnostics; safe support export; and raw probes/traces/debug overlay only through Advanced disclosure.

Use `./devtoolw aud-fix-11` for current validation.
